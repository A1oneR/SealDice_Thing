Windows食用方法：
1.打开你的PowerShell，CMD，或者其他类似的东西
2.安装依赖，输入pip install flask requests pillow openai python-docx PyPDF2 pymupdf，然后按回车，如果还有缺失的依赖请参考pip install xxx指令自行安装
3.用IDE（记事本）打开logai_server2_14.py，将配置区域的API_KEY，BASE_URL，MODEL替换为你所使用的大模型。
4.cd到对应的目录下方（例如：cd D:\logai_server），运行这个py，指令是python logai_server2_14.py
5.将JS插件（较新的Log分析器2_7以及模组分析器2）上传到海豹里面去。
6.测试指令，看有没有问题在。
有问题直接来找作者，作者会帮你问AI这是什么情况，当然也可以跳过问作者环节，直接问AI

更新log分析器到2.7版本，更新logai_server到2.14版本：
1. 新增【跑团/带团风格分析】功能：
   - 指令：.风格 [QQ号/玩家昵称/@某人] <Log链接或上传群文件>
   - 也支持指令：.logai 风格 [QQ号/玩家昵称/@某人] <Log链接或上传群文件>
   - 不带目标参数时，默认分析发送指令者自身。
2. 智能目标模糊匹配与聚焦：
   - 目标参数既可输入纯数字QQ号，也可输入角色昵称、前缀或后缀（如【.风格 严】可自动模糊匹配到【严茫熙】），无需完全一致。
   - 自动提取并聚焦目标玩家的全部发言、掷骰记录、RP描写与交互上下文。
3. 身份终审与动态报告大标题：
   - 由LLM结合全日志深度研判目标属于调查员/玩家（PL）还是守密人/主持（KP），避免传统规则误判；动态渲染大标题（例如【TRPG 玩家跑团风格报告】或【TRPG 主持带团风格报告】）。
4. 防幻觉熔断拦截机制：
   - 若在日志中未能匹配定位到该目标（如输入了不存在的昵称或错误QQ号），后端立即拦截并返回友好的候选角色列表与报错提示，不再将空目标交由LLM，杜绝大模型强行分析产生的幻觉。
5. 自动渲染六维风格能力雷达图：
   - 包含角色演绎、逻辑决策、团队协作、规则敏锐、临场应变、心理抗压等六维打分与雷达图可视化渲染，生成高清多图分段卡片。
6. 支持风格分析自定义配置（对号分析）与图表联动：
   - 指令：.风格 [QQ号/昵称] [自定义配置名] <Log链接或上传群文件>
   - 或：.风格 [自定义配置名] [QQ号/昵称] <Log链接或上传群文件>
   - 或省略目标：.风格 [自定义配置名] <Log链接或上传群文件>（自动对号分析发送者自身）。
   - 图表控制机制：与logai常规分析保持一致，仅当自定义提示词中明确要求图表/雷达图时才生成图表卡片（支持 ```logai-chart 雷达图/柱状图），若自定义提示词未要求图表，则输出纯文本报告，严格避免在未要求的情况下误加入图表。
7. 健全 PDF 跑团日志解析与 DOCX/TXT 转换：
   - 解决 PDF 格式日志在风格分析中由于多模态传参导致纯文本为空、无法命中的历史缺陷，构建健全的提取机制。
   - 采用 PyMuPDF（fitz，高精度排序与布局感知）优先 + PyPDF2 双层容错降级，保障各种 PDF 均能最大化解析。
   - 智能重构 TRPG 日志排版：自动识别并拼接被打印切断的时间戳、角色头与多行发言，过滤页眉页脚页码与网页打印 URL。
   - 自动转换易读文档并提供下载：PDF 提取后自动转换为排版规范的 `.docx` 和 `.txt` 文本，支持通过 `/api/download_converted?hash={hash}&format=docx/txt` 接口直接下载。
   - 纯图片扫描件与加密 PDF 智能拦截：自动识别未嵌入文字图层的纯图片扫描件 PDF、带有阅读密码的加密 PDF，拦截并生成友好提示卡片，明确告知无法读取的原因与操作建议（如直接上传 TXT/DOCX 或网页链接）。
