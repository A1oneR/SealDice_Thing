# 人工智障系列：从零搭建与使用指南

这是一套“海豹骰 JS 扩展 + Python 后端 + OpenAI 兼容大模型接口”的 TRPG 工具。它可以分析跑团 Log、分析/备团/完善/翻译模组、搜索百度网盘中的模组，还可以给 Excel 角色卡评分和生成图片。

本文由ChatGPT-5.6-Sol自动生成，由Air进行校对，如有疑问请咨询发包人。

本指南按目录中实际存在的代码整理，目标是让第一次接触海豹骰、Python 和 OneBot 的用户可以先搭出最小可用版本，再逐步打开其他功能。

## 先看结论

推荐新手先只安装下面两个文件：

1. `logai_server2_13.py` 与同目录的 `token_stats.py`：Python 后端及 Token 统计模块，监听 `8000` 端口。
2. `人工智障Log分析器2_6.js`：海豹骰 Log 分析扩展。

确认 `.logai` 可以工作后，再安装 `人工智障模组分析器2.js`。其他脚本都是可选项。不要同时上传 `人工智障Log分析器2_4.js`、`2_5.js`、`2_6.js`，也不要同时上传 `人工智障模组分析器.js` 和 `人工智障模组分析器2.js`；它们使用相同的扩展 ID，混装会造成重复注册或版本互相覆盖。

最稳妥的网络拓扑如下：

```text
QQ/NapCat/LLOneBot
        │ OneBot HTTP，例如 127.0.0.1:34567
        ▼
海豹骰核心 + JS 扩展
        │ HTTP POST/GET 到 127.0.0.1:8000
        ▼
logai_server2_13.py
        │
        ├─ OpenAI 兼容的大模型服务
        ├─ 可选：DeepSeek 备用模型
        ├─ 可选：NovelAI 生图
        └─ 可选：百度网盘 OpenAPI
```

`人工智障Log分析器2_6.js` 和 `人工智障模组分析器2.js` 将后端地址直接写成了 `http://127.0.0.1:8000`。因此，第一次搭建时请让海豹和 Python 后端运行在同一台机器、同一个网络命名空间中。若海豹在 Docker 容器、Python 在宿主机，`127.0.0.1` 指向的不是同一台服务，需要修改 JS 中的地址或调整容器网络。

## 1. 准备运行环境

### 1.1 必需软件

- Windows 10/11（目录原说明只在 Windows 上测试过）。
- 海豹骰版本建议 `1.5.1` 或更高，并能正常加载 JS 扩展。
- Python 建议 `3.11.9`。不要使用 Node.js 来运行 Python 后端，也不要用 Node.js 的 `require` 去运行海豹 JS；海豹 JS 运行在 goja 环境。
- 一个可以访问的 OpenAI 兼容 `chat/completions` 服务，以及对应 API Key。
- 一个 OneBot 客户端（NapCat、LLOneBot、Lagrange、Go-CQHTTP 等），并开启 HTTP API。

### 1.2 安全和费用准备

Log、模组和角色卡会被发送给你在 Python 中配置的大模型服务；`.logai` 的图片结果还会经过后端返回给机器人。开始前应告知群成员，不要上传不应外传的私人资料。

API Key 只放在本机脚本或环境变量中，不要把填好 Key 的脚本发到群里、提交到 Git 或上传到公开仓库。`logai_server2_13.py` 默认监听 `0.0.0.0:8000`，如果不需要局域网访问，请用防火墙限制 8000 端口，只让本机/机器人访问。

## 2. 配置 OneBot HTTP

在 NapCat/LLOneBot 等客户端中开启 OneBot HTTP 服务，记下：

- HTTP 地址，例如 `http://127.0.0.1:34567`
- 是否有访问令牌

目录中的 JS 默认不会添加鉴权请求头。如果你的 OneBot HTTP 开启了 Token，直接按默认脚本调用会返回 401；新手应先在本机关闭 Token，或自行给 JS 的 `fetch` 请求补上对应鉴权头。

先确认地址真的能被海豹所在环境访问。OneBot 地址是“海豹访问客户端”的地址，不是 QQ 群号，也不是 Python 后端地址。

## 3. 创建 Python 后端环境

打开 PowerShell，执行：

```powershell
cd "你的文件夹绝对路径"
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install flask requests pillow openai python-docx PyPDF2 pymupdf openpyxl "xlrd>=2.0.1" pandas
```

如果 PowerShell 禁止激活脚本，只对当前窗口放行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\.venv\Scripts\Activate.ps1
```

压缩包 `【更新】角色卡评分器，跑团活跃度计时器2.zip` 中还带有 `requirements.txt`，解压后也可以使用：

```powershell
python -m pip install -r "C:\路径\到\解压目录\requirements.txt"
```

看到 `Successfully installed` 后再进行下一步。以后每次启动后端前，都要先进入这个目录并激活 `.venv`。

## 4. 填写 Python 配置

用记事本或 VS Code 打开 `logai_server2_13.py`，只修改文件开头“配置区域”中的值。不要改变量名。

### 4.1 必填：主模型

```python
AI_API_KEY = "你的主模型Key"
AI_BASE_URL = "https://你的服务地址/v1"
AI_MODEL = "服务端支持的普通模型名"
AI_MODEL_PRO = "服务端支持的Pro模型名"
```

`AI_BASE_URL` 要填 OpenAI Python SDK 使用的根地址，通常以 `/v1` 结尾，不要填成完整的 `/chat/completions`。例如官方 OpenAI 兼容地址一般是 `https://api.openai.com/v1`。中转站必须以它的文档为准。

先只选一个确定可用的模型；如果普通模型和 Pro 模型暂时相同，可以先填相同值。模型名称必须是服务端真实支持的名称，代码不会替你自动探测模型。

### 4.2 可选：备用模型

```python
DS_API_KEY = os.getenv("LOGAI_BACKUP_API_KEY", "你的备用Key")
DS_BASE_URL = os.getenv("LOGAI_BACKUP_BASE_URL", "https://api.deepseek.com/v1")
DS_MODEL = "备用普通模型名"
DS_MODEL_PRO = "备用Pro模型名"
```

不需要备用模型时，可以暂时不使用 `ds`、`deepseek`、`backup` 参数。需要使用时，必须同时确认 Key、Base URL 和模型名可用。`2_6.js` 还可以用骰主指令 `.logai 备用模型 设置 <显示名> <普通模型ID> [Pro模型ID]` 保存多个备用模型。

### 4.3 Windows 字体和可选 Key

Windows 默认字体：

```python
FONT_PATH = "C:/Windows/Fonts/msyh.ttc"
```

如果本机没有该字体，换成实际存在的中文字体路径。下面这些是可选功能，未配置时不要安装对应 JS：

```python
IMAGE_API_KEY = "你的NovelAI Key"       # 人工智障生图.js
BAIDU_APP_KEY = "百度应用AppKey"        # 搜索模组
BAIDU_SECRET_KEY = "百度应用SecretKey"
BAIDU_AUTH_CODE = "百度授权码"
BAIDU_TARGET_DIR = "/你的百度网盘目录"
```

百度网盘授权码的获取地址在源码注释中，形如 `https://openapi.baidu.com/oauth/2.0/authorize?...`。`搜索模组` 只搜索 `BAIDU_TARGET_DIR` 下的内容，并会生成 `baidu_token.json`，请把这个文件当作密钥保护。

### 4.4 Linux 备注

Linux 用户应把 `FONT_PATH` 改成实际字体，例如目录说明给出的：

```python
FONT_PATH = "/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc"
```

再用 Linux 的 Python 3.11 虚拟环境安装同一组依赖。压缩包中的 Linux 反馈包含预编译核心和旧版源码补丁，但当前 `logai_server2_13.py` 已经针对新版海豹 JS 文件捕获方式工作；新手不要一开始就替换海豹核心，除非你明确知道自己正在运行旧版核心。

压缩包里的 `ds的修改建议.docx` 和 `patch_extract_text.py` 记录了一个旧版 NapCat 兼容补丁：当文件名丢失时，用文件头 `%PDF`、`PK\x03\x04` 推断为 PDF 或 DOCX。这个补丁实际附在旧的 `logai_server2_10` 修改版中，当前目录的 `logai_server2_13.py` 没有同样的 `recovered.pdf/recovered.docx` 自动命名逻辑。若你遇到“文件名未知/不支持的文件格式”，优先让新版 JS 从 CQ:file 的 `url` 直链下载；只有仍然失败时，才在备份后把该补丁移植到 `extract_text_from_file`，不要直接用压缩包里的旧后端替换 2_13。

看到类似下面的日志，说明 Flask 已开始监听：

```powershell
Invoke-RestMethod "http://127.0.0.1:8000/api/status?id=test"
```

## 7. 填写海豹扩展配置

在对应扩展的配置面板中修改下面的配置：

### 7.1 Log 分析器 `人工智障Log分析器2_6.js`

- `OneBot_API_地址`：填 OneBot HTTP 地址，例如 `http://127.0.0.1:34567`。末尾不要带 `/`。
- `支持的文件后缀`：默认 `.doc,.docx,.txt,.pdf,.md,.json,.yaml,.log`。
- `启用骰娘人设`：想使用自定义人设时打开；`ai` 参数可临时关闭人设。
- `每日Pro全局限额`：所有群每天共用的 Pro 次数；`0` 禁用，`-1` 无限。
- `每日单人Pro限额`：普通用户每天的 Pro 次数；`-1` 无限，管理员不受该单人限制。

### 7.2 模组分析器 `人工智障模组分析器2.js`

除以上 OneBot 和文件后缀外，还有：

- `HTTP客户端地址`：用于把搜索/翻译结果上传回群文件的客户端 HTTP 地址，通常和 OneBot 地址相同。
- Pro 限额和骰娘人设配置。

### 7.3 地址必须从“谁发请求”来理解

OneBot 地址是 JS 扩展访问 QQ 客户端的地址；后端地址是 JS 扩展访问 Python 的地址。主脚本中的后端地址固定为 `http://127.0.0.1:8000`，没有在 WebUI 中提供配置项。若跨机器部署，必须编辑 JS 中所有 `http://127.0.0.1:8000`，改成海豹能够访问的后端地址，并确保 QQ 客户端也能访问返回图片的 URL。

## 8. 第一次测试：先测 Log 链接

### 8.1 `.logai` 分析

在群里发送：

```text
.logai <Log链接>
```

源码支持三类链接格式：

- `log.weizaima.com/?key=...#密码`
- `logpainter.trpgbot.com/...#...`
- `logpainter.kokona.tech/?s3=...`

常用参数：

```text
.logai <链接> pro       # Pro 模型
.logai <链接> 温柔      # 温柔骰娘人设
.logai <链接> ai        # 关闭骰娘人设，使用原版专业提示词
.logai <链接> ds        # 使用已配置的备用模型
.前文回顾 <链接>        # 只梳理剧情进度和线索
```

后端会先返回任务 ID，JS 每 2 秒轮询一次，最多等待约 3 分钟。结果通常是 PNG 图片；模型慢或失败时，看 Python 窗口中的日志。

### 8.2 用本地群文件分析

1. 在群里上传一个 `.log`、`.txt`、`.docx` 或其他已允许的文件。
2. 发送 `.logai 文件状态`，确认扩展已捕获文件、`file_id` 存在。
3. 发送 `.logai`，不带链接，扩展会调用 OneBot 的 `get_group_file_url` 获取下载直链。

如果 `.logai 文件状态` 显示没有文件，通常是文件后缀不在允许列表、OneBot 没有上报 CQ:file、或旧版客户端需要源码补丁。先检查 JS 控制台和 OneBot 地址，不要立即替换海豹源码。

## 9. 模组分析、翻译和搜索

启用 `人工智障模组分析器2.js` 后，先在群里上传模组文件，再发送：

```text
.模组分析
.模组分析 pro
.模组分析 温柔
.模组备团
.模组完善
```

支持的常见后缀来自配置，默认包括 `.doc`、`.docx`、`.txt`、`.pdf`、`.md`、`.json`、`.yaml`。`覆盖` 表示翻译后尽量覆盖原文；不带 `覆盖` 时会保留原文并生成新文件。

百度网盘搜索需要先完成 Python 配置中的百度 Key、Secret、授权码和目录：


“本地”模式会限制搜索范围和下载数量，以避免一次下载过多文件；它还需要 `HTTP客户端地址` 能访问客户端的 `upload_group_file` 接口。

## 12. 可选：跑团活跃度计时器

压缩包中的 `跑团活跃度计时器.js` 提供：

```text
.log on 或 .log new
.log off 或 .log end
.团计时 状态
.团计时 玩家 @A @B
.团计时 排除 @A
.团计时 纳入 @A
.团计时 名单
.团计时 历史
```

当前目录的 `logai_server2_13.py` 已从 `logai_server/logai_server2_12.py` 补入计时器需要的接口：

- `/api/session_review`：在后端线程池中调用 OpenAI 兼容模型生成复盘，可同时排版成图片。
- `/api/result_base64`：把生成的 PNG 转成 Base64，交给海豹中转给 QQ 客户端。
- `/api/session_archive`：启用“后台上报地址”时，异步转发本场统计 JSON。
- `/api/status`：现在会同时返回复盘正文 `text` 和图片数量。

上传并启用 `跑团活跃度计时器.js` 后，在扩展配置中填写：

- `LogAI_Server地址 = http://127.0.0.1:8000`：只填根地址，不要附加 `/api`。
- `LLM_API地址`：必须是完整的 OpenAI 兼容接口，例如 `https://你的服务/v1/chat/completions`。这里与 Python 顶部的 `AI_BASE_URL` 不同，必须包含 `/chat/completions`。
- `LLM_API密钥`：远程模型接口必填；仅 `127.0.0.1` 或 `localhost` 的无鉴权模型端点可留空。
- `LLM模型`：填写该接口实际支持的模型 ID。
- `启用LLM分析 = true`：打开智能复盘；首次排错时也可以先关闭，只验证客观统计。
- `统计转为图片 = true`、`复盘转为图片 = true`：调用 2_13 的图片排版接口。

图片发送方式按部署环境选择：

- `URL直传`：QQ 客户端能够访问 LogAI Server 时使用。跨机器部署时在“图片公开地址”填 QQ 客户端可访问的局域网或公网根地址。
- `Base64直传`：QQ 客户端访问不到 `127.0.0.1:8000` 时使用；海豹会调用 `/api/result_base64` 取回图片并中转，代价是消息和内存占用更高。

`/api/session_review` 和 `/api/session_archive` 出于安全考虑只接受来自本机回环地址的请求。因此计时器与 Python 后端默认需要处于同一个网络命名空间；若海豹和后端分属不同 Docker 容器，即使端口可达也会收到 403，需要统一网络部署或自行调整后端的来源限制。

建议按下面顺序测试：

1. 重启 `logai_server2_13.py`，确保新路由生效。
2. 暂时设置 `启用LLM分析 = false`，执行 `.log on`，发送几条非指令消息，再执行 `.log off`，确认客观统计正常。
3. 打开 `启用LLM分析`，填写完整 `LLM_API地址`、密钥和模型，再跑一轮短测试。
4. URL 图片无法显示时，切换为 `Base64直传` 再试。

计时器会保存限长聊天原文并可能发送给模型。开团前应告知参与者；不需要原文时关闭“记录聊天原文”或“向LLM发送聊天原文”。“后台上报地址”留空时不会向额外服务器上传统计。

## 13. 可选：结团自动分析

### Token 消耗排行

更新后的后端会把实际发生的模型调用追加到同目录的 `token_usage.jsonl`，并按 QQ 用户、功能模块和提示词缩略聚合。模型服务返回 `usage` 时使用精确值；不返回时按输入输出字符数估算，并在榜单中标记估算量。缓存命中不会重复计费，也不会保存完整提示词。

在安装更新版 `人工智障Log分析器2_6.js` 后使用：

```text
.Token排行       # 默认近 30 天
.Token排行 7     # 近 7 天
.Token排行 0     # 全部历史
```

指令会发送用户榜、模块榜与高频提示词缩略两张图片。统计从更新部署后开始，无法从旧报告图片反推历史 Token。`/api/token_stats` 和 `/api/token_rankings` 只接受本机请求；不要公开 `token_usage.jsonl`，其中虽无完整提示词，但包含 QQ、昵称和提示词缩略。

用户榜显示的是 OneBot `get_stranger_info` 查询到的账号真实昵称，不使用群名片/群昵称；查询失败时显示“匿名用户”。QQ 号仅用于账本内部合并统计，不会绘制到排行榜图片中。

### 多 Log 链接合并分析

`.logai` 支持一次提交多个链接，按输入顺序下载、清洗并拼接后只调用一次模型：

```text
.logai 链接1 链接2
.logai 链接1 链接2 链接3 pro 克苏鲁
```

每段 Log 会加入“第 N 段 Log”分隔标记，最多 20 段。某段读取失败时会跳过并在 Python 后台记录警告；全部链接都失败才会报错。单链接写法和本地群文件分析不受影响。

`结团自动分析 (配合ai裁判（人工智障插件)，需要自行修改检测关键词和关键词触发指令.js` 会监听海豹发出的消息，寻找 `log.weizaima.com/?key=...` 链接，然后直接调用已加载的 `log-analyzer` 扩展的 `.logai` 指令。

安装顺序必须是：

1. 先启用 `人工智障Log分析器2_6.js`。
2. 确认手动 `.logai` 能用。
3. 再启用自动分析脚本。

该脚本只识别源码中列出的固定提示语和 `log.weizaima.com` 格式。若你的结团插件输出文案或链接格式不同，需要自行修改 `successPhrases` 和 `urlPattern`。

## 14. 故障排查

| 现象 | 优先检查 |
| --- | --- |
| `ModuleNotFoundError` | 是否激活 `.venv`；是否安装了 `flask requests pillow openai python-docx PyPDF2 pymupdf openpyxl xlrd pandas` |
| 后端启动即报 Key/模型错误 | 检查 `AI_API_KEY`、`AI_BASE_URL`、`AI_MODEL`；Base URL 不要误填完整 chat 路径 |
| `Invoke-RestMethod /api/status` 连接失败 | Python 进程是否仍在运行；8000 是否被占用；防火墙是否拦截 |
| `.logai <链接>` 能提交但一直失败 | 看 Python 控制台；检查模型服务额度、网络、模型名和返回格式 |
| `.logai 文件状态` 没有文件 | 检查后缀、OneBot HTTP 地址和 CQ:file 上报；先不要替换海豹源码 |
| 获取群文件直链失败 | OneBot 是否支持 `get_group_file_url`；HTTP Token 是否导致 401；NapCat 可检查 CQ:file 中是否带 `url=` 直链 |
| 文件名显示“未知文件”且后端说格式不支持 | 当前 2_13 未内置旧版 magic-bytes 自动命名补丁；优先确保 CQ:file 带 `url` 和正确文件名，必要时再移植 `patch_extract_text.py` |
| 返回图片但 QQ 显示失败 | QQ 客户端是否能访问图片 URL；跨机器时不要使用只能本机访问的 `127.0.0.1` |
| 模组翻译完成但没上传回群 | `HTTP客户端地址` 是否正确；客户端是否支持 `upload_group_file` |
| `.搜索模组` 报授权问题 | 百度 AppKey、Secret、授权码、`BAIDU_TARGET_DIR` 是否正确；删除过期的 `baidu_token.json` 后重新授权 |
| 角色卡识别为空 | 只支持 xlsx/xls/csv；检查工作表命名和后端日志；先用 `.角色卡评分` 不带 `dnd` 测试 |
| 计时器提交复盘返回 403 | `/api/session_review` 只允许回环地址；确认海豹与 Python 在同一网络命名空间，不要跨 Docker 容器直接调用 |
| 计时器复盘提示 `api_url 必须指向 /chat/completions` | `LLM_API地址` 必须填写完整 chat/completions 地址，而不是只填 `/v1` 根地址 |
| URL 图片无法显示 | 填写 QQ 客户端能访问的“图片公开地址”，或把“图片发送方式”改为 `Base64直传` |
| 上传 JS 后指令重复 | 删除/停用旧版同功能脚本，只保留 2_6 和 2.js，重载 JS |

## 15. 建议的最小验收清单

按下面顺序验收，不要一次打开所有功能：

1. `Invoke-RestMethod http://127.0.0.1:8000/api/status?id=test` 返回 `not_found`。
2. 海豹扩展列表中只有一个 `log-analyzer`。
3. `.logai <一个公开可访问的 Log 链接>` 能返回 PNG。
4. 群里上传 `.log` 后，`.logai 文件状态` 能显示文件名和 `file_id`。
5. `.logai` 不带链接能分析刚上传的文件。
6. 上传模组后，`.模组分析` 能返回结果。
7. 启用计时器后，用 `.log on`、几条测试消息、`.log off` 验证客观统计和智能复盘。
8. 需要时再增加角色卡评分、生图和网盘搜索。

遇到问题时，保留三份信息再求助：海豹 JS 控制台完整报错、Python 后端窗口从“提交任务”开始的日志、OneBot HTTP 请求返回的状态码。不要只说“不能用”，这三份信息通常可以直接定位问题是在海豹、OneBot、Python 还是模型服务。

## 16. 更新和备份

- 更新 JS 前先复制当前能工作的脚本和海豹扩展数据。
- 更新 Python 前先备份 `logai_server2_13.py`、`.venv` 之外的配置、`sheet_cards` 和 `baidu_token.json`。
- 每次只替换一个组件，重启后端并跑一遍第 15 节验收清单。
- 不要把 `人工智障Log分析器2_4.js`、`2_5.js`、`2_6.js` 视为可叠加插件；它们是同一个 `log-analyzer` 扩展的不同版本。
