# 指令手册

所有功能同时支持 `.yan <板块> ...` 和独立短指令。去掉 `yan` 后，原板块名直接成为指令：`.yan 我的 钓鱼` 等价于 `.我的 钓鱼`，`.yan 快艇 投掷` 等价于 `.快艇 投掷`。下文保留 `.yan` 完整写法，所有示例均可按此规则缩短。

## 档案与成长

| 指令 | 说明 |
| --- | --- |
| `.yan 注册 <名字>` | 首次使用必须登记；名字为1至9个字，登记后插件始终使用该名字 |
| `.yan 改名 <新名字>` | 修改登记名；长度仍为1至9个字，并同步当前房间与钓鱼进度 |
| `.yan 我的` | 查看钱包、好感阶段和各项目摘要 |
| `.yan 我的 <项目>` | 查看某个项目的彩色详细统计；也可写作 `.yan 统计 <项目>` |
| `.yan 签到` | 每个自然日一次；按1:3:6权重抽取最好的、较好的或日常待遇 |
| `.yan 投喂` | 查看食物菜单 |
| `.yan 投喂 <食物>` | 花费游戏币换取好感 |
| `.yan 借款 [申请]` | 查看借款账页；余额低于150时可申请150游戏币 |
| `.yan 排行 [项目]` | 项目可为综合、好感、金币、德州、21点、神抽、刮刮、快艇、爱赢一切、古墓、钓鱼、竞拍 |

## 房间通用约定

德州、亡命神抽、Farkle、爱赢一切和古墓夺宝使用一致的收费房间操作；竞拍之王也支持开房、加入、机器人、开始、状态、退出和清理，但不收固定门票，而是在暗标时锁定游戏币：

| 子指令 | 说明 |
| --- | --- |
| `人机` | 创建 1v1 人机房并立即开始 |
| `开房` | 创建真人房；余额足够则支付入场费，否则以游客身份创建 |
| `加入` | 加入当前群等待中的房间；余额足够则支付入场费，否则以游客身份加入 |
| `机器人 [1-5]` | 房主添加机器人，总人数最多 6 |
| `开始` | 房主开始游戏 |
| `状态` | 查看当前局面 |
| `退出` | 仅等待阶段可退出；付费玩家全额退款，游客没有费用可退 |
| `清理` | 清理已结束房；房主清理等待房会给真人退款 |

每个群、每个游戏同时只有一个房间。过期等待房会自动退款；普通模块的过期进行中房会清理但不退款。竞拍房的暗标是可追踪的锁定资金，因此过期清理时会先逐人退回尚未结算的锁定游戏币。

游客适用于德州、亡命神抽、Farkle、爱赢一切、古墓夺宝和竞拍之王的多人房。五个固定入场费模块的游客不扣入场费；竞拍游客获得默认 500000 竞拍币虚拟预算。赏金对决不收取入场费，也不产生赏金游客分支。游客仍有正常座位、回合和全部操作，也参与最终排名；但游戏币、好感、局数、胜负、项目分、最大牌型、大满贯、带出宝物和货品图鉴等永久数据全部不结算。德州、亡命神抽、Farkle、爱赢一切和古墓夺宝的人机模式仍要求足额支付入场费；竞拍人机局也允许零余额玩家以游客身份熟悉玩法。图片座位和文字状态会显示“游客”，结算卡显示“不计档案”。

德州、21点、亡命神抽、Farkle 和爱赢一切的付费唯一胜者会在好感奖励之外获得两倍该项目入场费；扣除开局成本后，游戏币净赚一倍入场费。并列第一按平局处理，不发放该回报；游客即使获得第一名也不返奖。

德州、21点、亡命神抽、Farkle、爱赢一切、古墓夺宝、钓鱼和竞拍结算后，可以用显式的 `状态` 指令继续复查最后一次结算。之后直接发送无参数入口（例如 `.yan 钓鱼`、`.yan 德州`、`.yan 古墓` 或 `.yan 爱赢一切`）会清除已结算快照并返回该模块最开始的帮助界面；等待中或进行中的局面不会被清除。刮刮乐在刮开时立即清除旧票，再次发送 `.yan 刮刮` 会直接显示购票帮助。

## 德州扑克

```text
.yan 德州 人机
.yan 德州 教程 [页码]
.yan 德州 开房
.yan 德州 加入
.yan 德州 机器人 2
.yan 德州 开始
.yan 德州 看牌
.yan 德州 过牌
.yan 德州 跟注
.yan 德州 加注 50
.yan 德州 全押
.yan 德州 弃牌
.yan 德州 状态
.yan 德州 下一手
.yan 德州 下一局
```

PvE 人机赌桌会在群图中直接常亮真人的两张底牌，Bot 的决策逻辑仍只读取自身底牌和公共牌；PvP/PvPvE 的未摊牌底牌继续画成牌背，`.yan 德州 看牌` 可私聊查看自己的牌。中央固定显示五个公共牌槽，每位玩家的本轮下注位于对应座位框下方；阶段标签位于顶部手牌下方，底池与当前注左右分列，行动日志居中排版。教程共两页，包含淘汰赛流程、指令与全部牌型。机器人姓名只从姜修泽、葛明治、阿日、严茫熙和亨德森中选取。

150 游戏币只在整场淘汰赛开始时扣除一次，并转换为 150 桌面筹码。每手底池结算后，未归零玩家保留当前筹码；此时牌桌停在完整摊牌画面并显示暂定排名，任意本桌真人发送 `.yan 德州 下一手` 即可轮转庄位并继续发牌，不会再次扣费。只有筹码归零者才退场，整场一直打到只剩一名玩家持有筹码为止。

玩家每次实际进入摊牌并完成七选五牌型计算时，档案都会更新自己的“历史最大牌型”；弃牌且未摊牌的底牌不计入。记录会先比较同花顺、四条、葫芦等牌型等级，同一牌型继续比较关键点数。`.yan 我的` 的德州摘要和 `.yan 我的 德州` 的彩色详细统计都会显示该纪录；升级前无法反推的旧对局显示“尚无摊牌记录”。

最终排名按退场先后倒序确定：越晚淘汰名次越高，最后仍有筹码者为第一名。同一手有多人同时归零时，以该手开始前的筹码量区分，筹码较多者排名较高；筹码也相同则按座位顺序稳定处理。只有整场结束才写入项目战绩、好感和两倍入场费回报。整场结算后发送 `.yan 德州 下一局` 才会重新支付 150：人机桌保留原 Bot 并立即开始新淘汰赛；多人桌由原房主发起，其他真人重新 `.yan 德州 加入` 确认付费，再由房主开始。无参数 `.yan 德州` 会清除最终快照并返回初始帮助。

## 生化危机 7 二十一点

```text
.yan 21点 开始
.yan 21点 教程 [页码]
.yan 21点 抽牌
.yan 21点 停牌
.yan 21点 出牌 <完整王牌名>
.yan 21点 状态
.yan 21点 放弃
.yan 21点 清理
```

每回合使用 1-11 共 11 张不重复数字牌。双方初始 5 HP；输掉回合时按场上赌注伤害扣 HP，直到一方归零。王牌名应完整输入，例如 `挑战24点`、`数字7+`、`护盾攻击+`。

轮到自己时可以连续使用任意数量的王牌，成功出王牌不会自动交换行动方。只有成功摸取数字牌或选择停牌，才会结束自己的本次行动并把行动权交给对手；牌效明确写有“跳过自己回合”等字样时除外。停牌并不代表永久退出本回合：对手随后只要摸牌或使用王牌，旧的停牌标记便会失效，行动权回来后仍需继续行动或反制。只有双方连续以停牌结束行动、且两次停牌之间没有其他操作时才结算。结算后牌桌会停在双方最终牌面，不能继续停牌或使用王牌；下一回合由本轮输家先手，若平局则交换一次先手。玩家看清点数、胜负、伤害与下一先手后，发送 `.yan 21点 抽牌` 才会发出下一回合的初始手牌；轮到骰娘先手时，骰娘会先完成行动。

爆牌不会立即结算，只会禁止继续普通摸牌，爆牌者仍可在后续行动中使用 `退回`、`交换`、挑战牌等王牌修正局面，也可以停牌交出行动权。敌方不会仅因爆牌而翻开原本的暗牌。每个新回合双方各获得一张王牌，未使用王牌保留到下个回合；普通摸牌默认有 25% 概率再获得一张，此概率可通过 `21点摸牌获得王牌概率` 配置修改。敌方获得王牌时只显示新增数量而不显示名称，实际使用后才公开牌名；即使紧接着停牌，桌面行动记录也会同时保留使用牌名与停牌动作。

`挑战17点`、`挑战24点`、`挑战27点` 是场上规则牌。新的挑战牌会替换旧挑战；挑战牌被 `破坏`、`破坏+` 或 `破坏++` 清除后，目标立即恢复为21点，并按21点重新判断双方是否爆牌。

面对面牌桌图会显示双方数字牌、HP、点数或隐藏状态、行动状态、场上持续王牌，以及玩家手中的王牌。`遗忘`会抹去当前回合并按原先手立即重开；如果重开后仍由骰娘先手，骰娘会在同一次指令中自动完成行动，不会留下无法继续驱动的敌方回合。Bot 连续牌效还设有最终安全交权，达到行动上限时会自动停牌。回合结算时中央会切换为结算面板，明确显示最终点数对比、回合胜者、受伤者与伤害，并提示下一回合指令。分页教程第一页说明完整流程，后续页面从实际王牌数据库生成全部牌效；发送 `.yan 21点 教程 2` 等指令切换页面。

## 亡命神抽

```text
.yan 神抽 人机
.yan 神抽 教程 [页码]
.yan 神抽 开房 / 加入 / 机器人 2 / 开始
.yan 神抽 抽牌
.yan 神抽 收手
.yan 神抽 状态
.yan 神抽 使用 美人鱼 <甲板牌ID>
.yan 神抽 使用 藏宝图 <选项序号或牌ID>
.yan 神抽 使用 弯刀 <牌ID> <目标名字/座位>
.yan 神抽 使用 钩子 <自己的战利品牌ID>
.yan 神抽 使用 大炮 <牌ID> <目标名字/座位>
```

同花色第二张进入甲板会爆炸。船锚保护其之前的牌；海怪强制追加抽牌；钥匙与宝箱组合可从弃牌堆追加战利品。单回合收齐十种花色即大满贯，默认额外增加 60 好感。

每个项目分别记录局数、胜负平、累计项目分、最高纪录、游戏币净收益、累计获得好感、累计失去好感和好感净变化。亡命神抽还会额外记录大满贯次数。

抽到美人鱼、弯刀、钩子或大炮且存在合法目标时，会进入强制待处理状态；处理前不能继续抽牌或收手，也不能放弃。只有完全没有合法目标时，该效果才会自动失效。藏宝图会从弃牌堆取出至多三张，必须选择并获得其中一张；该牌加入甲板后会照常检查爆炸并触发自己的牌效。牌 ID 由花色字母和数字组成，例如 `M3`、`D5`、`P7`，也可以直接输入图片中显示的选项序号。

帮助、等待、进行中和结算状态都会生成专用甲板桌。中央显示当前甲板与十花色风险，左右显示牌库和弃牌堆；玩家座位卡用十个彩色格显示各花色的顶牌点数。出现强制效果时，中央区域会切换为目标选择面板，并给出可直接使用的牌 ID 和指令格式。三页图片教程依次讲解完整流程与大满贯、十种花色牌效、强制道具的目标与指令格式。

## Farkle 快艇骰

```text
.yan 快艇 人机
.yan 快艇 教程 [页码]
.yan 快艇 开房 / 加入 / 机器人 2 / 开始
.yan 快艇 投掷
.yan 快艇 选择 1,1,5
.yan 快艇 存分
.yan 快艇 状态
```

选择值按实际骰面输入并用逗号分隔。选择中的每一枚骰子都必须参与计分；六枚全部计分后触发热骰。任一玩家存分后达到 5000 即结算。

所有状态都会生成专用快艇骰桌：中央六枚骰子按真实点数绘制，1 和 5 使用红色骰点提示其可单独计分；玩家座位卡显示总分、回合暂存、最佳回合和 5000 分目标进度。选择阶段会给出当前骰面的最高可计分组合分值，结算时座位卡直接显示名次、好感变化和游戏币回报。

玩家投出无有效计分组合时立即 Farkle，本回合暂存分归零并换人。人机局中的 Bot 会继续自动完成自己的投掷过程；返回给玩家的牌桌会把玩家刚才的爆骰骰面作为“上一轮回看”保留下来，同时显示 Bot 上一轮实际入账多少分，若 Bot 也 Farkle 则明确显示入账 0 分。回看骰面只用于显示，真实房间骰面已经清空，不会被下一步选择指令误用。

两页图片教程分别说明 5000 分目标、投掷/选择/继续/存分、Farkle 与热骰流程，以及单 1、单 5、三条、四至六条、六股顺子和三对的全部计分规则。默认是规则1；等待房间时可用 `.快艇 规则 2` 切换扩展规则2，也可用 `.快艇 人机 2` 或 `.快艇 开房 2` 开局。规则2新增 1-5/2-6 五骰小顺子 750 分，以及六骰完全没有标准得分组合时的 500 分保底；牌局开始后规则锁定。

## 爱赢一切

```text
.yan 爱赢一切 人机
.yan 爱赢一切 教程 [页码]
.yan 爱赢一切 开房 / 加入 / 机器人 / 开始
.yan 爱赢一切 过牌
.yan 爱赢一切 跟注
.yan 爱赢一切 加注 <本阶段总下注>
.yan 爱赢一切 全押
.yan 爱赢一切 弃牌
.yan 爱赢一切 公开 <1-3> <牌型> [公共骗子指定]
.yan 爱赢一切 确认公开
.yan 爱赢一切 下一轮
.yan 爱赢一切 状态
.yan 爱赢一切 投降
.yan 爱赢一切 清理
```

本模块固定1v1，支持PvE和PvP，入场费100游戏币。双方开局各有20枚桌面筹码，每轮先各支付1枚底注。49张牌库由18张剪刀（蓝）、12张石头（红）、12张布（黄）、6张爱（绿）和1张骗子（粉）组成。每轮每人先拿2张暗牌，场中公开1张公共牌；第一轮下注金额相同后，每人再获得1张最终补牌。双方分别锁定要公开的1张手牌与宣告，只有同步公开后才进入第二轮下注，下注再次相同才完整摊牌。加注参数是“本阶段总下注”，系统会限制到对手能够跟到的金额，不产生无人可争夺的边池。

如果第一轮有人全押且对手完成跟注，则已经没有后续下注决策：系统仍会补发双方最终手牌，但会跳过公开手牌、宣告牌型和第二轮下注，直接展开完整牌面结算。公共骗子牌和私人骗子牌在这条直摊路径中会自动选择各自能够形成的最佳合法效果。

牌型从小到大为：`1爱 < 1对 < 3条 < 2对 < 2爱 < 混合 < 4条 < 3爱 < 爱赢一切`。混合必须正好是剪刀、石头、布、爱各一张；1爱是没有组成混合的单爱牌型。除最小的1爱外，同牌型按石头克剪刀、剪刀克布、布克石头比较；相同部分先抵消，再比较剩余牌。2爱比较剩余两张普通牌，3爱比较剩余一张，2对抵消双方共有的对子后再比较另一对。混合与四张爱通常为平局。

宣告只受两张公开牌限制：只要公共牌和自己公开的那张手牌能够补成目标牌型，就可以这样宣告，不要求与两张暗牌组成的真实最终牌型一致。普通牌手可以借此诈唬，但摊牌仍按真实四张牌结算。私人骗子牌不会简单替换一张牌，而是让持有者“把合法宣告说成真的”。若双方最终牌型相同且只有一方持私人骗子牌，持骗子牌的一方直接落败，不再比较剩余牌；持私人骗子牌输掉本轮时，还要从剩余筹码中额外支付对方最多5枚。公共牌是骗子时，双方各自指定它为剪刀、石头、布或爱，不触发私人骗子罚则；指令示例为 `.爱赢一切 公开 2 3爱 爱`。

首轮先手随机，之后由上一轮败方先手；平局则交换一次先手。弃牌只放弃当前轮，`.爱赢一切 投降`才会结束整场。每轮结算图会展开双方完整牌面并停留，玩家确认后发送 `.爱赢一切 下一轮`。每打满七轮或剩余牌不足以发出完整新一轮时，系统重新生成并洗好49张牌，同时把双方现有筹码向上取整减半，再继续新一副牌；整场只在一方筹码归零或主动投降时结算。付费唯一胜者返还200游戏币，失败好感损失绝对值大于胜利增加。多人余额不足者可作为游客入场，但不结算奖励、好感或统计。

PvE 群图会持续常亮真人的全部手牌，Bot 决策仍不能读取这些暗牌；Bot 先私下锁定，真人在群内发送 `.爱赢一切 公开 ...` 后双方立即同时展示。PvP 中两位玩家都必须私聊骰娘发送公开指令，群图只显示“已锁定”状态，不会提前泄露位置或宣告；双方均锁定后，任一在座玩家回群发送 `.爱赢一切 确认公开`，双方才会同时翻牌。四页图片教程依次说明牌库与流程、九档牌型、骗子牌和终局/指令。`.我的 爱赢一切`额外统计赢下轮次、四爱成型次数、骗子牌胜负、额外罚筹码、终局最高筹码与历史最高牌型。

“.yan 打工 开始”是正式打工入口，不带题型时从四种普通题型随机抽取；指定题型、新题和旧热身指令仍可使用，但不计正式工资。答对后会自动进入下一题，图片侧栏展示上一题的答题耗时、难度和报酬。发送“.yan 打工 结束”会停止发题并结算本班，汇总领取题数、完成/失败/跳过、错误提交、用时、平均难度、毛报酬和实收；结算后无参数“.yan 打工”回到帮助界面。报酬以题目难度为主要基准，答题时长只提供最低保底；余额达到 200 后普通题毛报酬只记录历史、不再入账。

“.yan 打工 专家数独”单独生成高难度旋转对称数独，母版经 Sudoku Coach 校准为 `SE≈8.1 / Beyond Hell (10)`，仅做保持难度的同构随机化；允许两次错误，机会用完后显示答案。专家题每次只发一道，答对、失败或结束后都不会自动进入下一题，需重新发送指令；专家题不受余额上限限制，单题最高 100 游戏币。题面每次由服务端校验唯一解，渲染器不接收答案，同时记录异常过快提交；这些措施用于降低直接套用外部 SudokuSolver 的收益，不宣称绝对防作弊。

- **24点**：系统先随机四个数字，再计算完整解空间；题面会标明是否无解、是否需要小数。四个数字各使用一次组成24，支持小数中间结果；`x`、`*`、`×` 都是乘号，也可以提交“无解”。
- **数独**：系统先随机打乱合法完整盘面再挖空，图片使用灰色细格线，并为九个3×3九宫格分别绘制一次金色外框；题面会确认只有一个完整解。答案可提交完整81个数字，也可只按从左到右、从上到下提交原题空格中的数字，空格和换行会自动忽略。
- **骑士与无赖**：骑士说真话、无赖说假话，人数随机3至8人。新题会让每个人的身份/结盟陈述尽量连接到前面的人物，并枚举全部身份组合确认唯一解，不需要先知道骑士和无赖各有多少人；答案支持 `FTTFFT` 或 `1F2T3T4F5F6T`，两种格式等价。旧版题面也会按可识别的中文陈述重新验算。
- **Creek溪流**：系统随机生成4×6至10×12棋盘，图片使用完整长方形边框围住题面，只在内部交点显示数字节点，外围不再堆叠数字。内部顶点数字表示相邻四格的雷数；系统会按这些真正可见的线索预先求解，只发放恰好有一个合法答案的新题。旧版尚未完成的多解题会接受任意满足可见线索的答案。答案按行提交全部格子，雷写1、空格写0，空格和换行会自动忽略。
