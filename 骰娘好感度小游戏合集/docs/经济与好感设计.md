# 经济与好感设计

## 默认经济

| 项目 | 默认值 |
| --- | ---: |
| 新玩家初始游戏币 | 500 |
| 每日签到游戏币 | 100 |
| 每日签到好感 | +5 |
| 德州扑克整场入场 | 150（每场淘汰赛仅一次） |
| 21 点入场 | 100 |
| 21 点普通摸牌额外王牌概率 | 25% |
| 亡命神抽入场 | 100 |
| Farkle 入场 | 100 |
| 爱赢一切入场 | 100（每场转换为20枚桌面筹码） |
| 竞拍币兑换 | 1 游戏币 = 10000 竞拍币 |
| 竞拍游客虚拟预算 | 500000 竞拍币 |
| 对决获胜游戏币回报 | 发放该项目两倍入场费 |
| 小鱼塘 / 江水 / 大海 | 10 / 50 / 100 |
| 刮刮乐面额 | 10 / 50 / 100 / 500 |
| 双色球单注 | 10 |
| 生死骰简单 / 困难生还倍率 | 1.2 / 3 |
| 借款到账 / 每笔应还 / 还款触发余额 | 150 / 195 / 345 |
| 借款首次 / 每笔叠加好感损失 | 20 / 10 |

21 点人机局以及德州、亡命神抽、Farkle、爱赢一切的人机局会在开局时扣除入场费。后四者的多人房若余额不足则改为游客入场：不扣费，仍能完整操作并参与排名，但钱包、好感、局数、胜负、项目分、最大牌型和大满贯等永久数据全部不结算。付费的 1v1 胜者或多人唯一第一名在结算时发放两倍入场费，因此胜者该局游戏币净赚一倍入场费，失败者净收益为负入场费；游客第一名不返奖。德州的 150 只在整场淘汰赛开始时扣除一次，后续各手继承桌面筹码，`.德州 下一手` 不收费；只有最后剩一人有筹码时才结算整场。爱赢一切的20枚筹码同样只用于牌桌排名，不兑换回钱包。机器人不建立钱包，也不会产生返奖。刮刮乐、钓鱼与竞拍仍可产生额外的正游戏币收益。

刮刮乐倍率池的理论返还约为票价的 71%。最终奖金在生成和兑付两个阶段都会执行 `0..面额*100` 钳制，即使存储数据被意外写坏也不会突破上限。

双色球每注默认10币，每天18:00生成5个红球和1个蓝球；彩票开奖与兑奖不结算好感。固定奖金从仅中蓝球的10币到5红1蓝的1000币。购票成本立即计入刮刮板块净收益，奖金在主动兑奖时入账；中奖彩票在下一次18:00前未兑奖会过期。

生死骰使用当前全部余额作为押注。简单模式生还余额为 `floor(押注×1.2)`，困难模式为 `押注×3`，死亡时归零；两种结果都不改变好感。若生还返还使余额达到借款还款线，会在保存结果时继续执行自动还款。

借款每笔到账150、应还195。首次好感损失和未还借款叠加损失分别由同名配置控制，默认20和10。余额每次达到345就按先借先还收回一笔195，并恢复该笔好感损失的50%（向下取整）；如果余额足以连续结算多笔，会持续结算到余额低于345或债务清空。

竞拍之王不收固定入场费。正式玩家每次修改暗标时，系统按每 10000 竞拍币锁定 1 游戏币：加价补锁差额，降价立即退回减少的差额，相同金额不会重复扣款。主动放弃、落拍、流拍、房间过期或已结束房清理时，非成交者的锁定游戏币全部退回。成交者开箱后将货品立即出售，出售收入按完整的 10000 竞拍币单位折算回游戏币；不足 10000 的尾数不入账。助手不再直接改变成交返款，避免商品情报型助手与经济型助手出现不可比较的固定收益。旧1:1000房间不会沿用新比例结算，加载时会先按记录的 `heldCoins` 原数退款，再清理房间。

余额为零的竞拍玩家会成为游客，使用 `竞拍游客预算` 配置提供的虚拟竞拍币，默认 500000。游客可以出价、使用助手与道具、提前成交和查看完整开箱，但不改变钱包，不结算好感、胜负、利润、最高出价或货品图鉴。机器人预算、暗标与开箱也不建立钱包记录。

## 关系阶段

| 阶段 | 好感区间 |
| --- | ---: |
| 厌恶 | 小于 -100 |
| 疏离 | -100 到 -1 |
| 初见 | 0 到 99 |
| 熟悉 | 100 到 299 |
| 亲近 | 300 到 699 |
| 信赖 | 700 到 1499 |
| 心动 | 1500 到 2999 |
| 钟情 | 3000 及以上 |

八个阶段分别对应 `文案_厌恶` 到 `文案_钟情` 的 Template 配置。事件文案另有签到、余额不足、胜利、失败、投喂、大满贯、钓鱼收杆、双色球、生死骰、借款和还款配置。

所有 `文案_*` 配置都是随机候选池。可在插件配置页点击“＋”增加条目并保存；每次触发时都会重新读取当前列表并忽略空条目。没有权重前缀时各条目等权，并会避免连续两次出现完全相同的句子；需要降低或提高相对出现频率时，可使用海豹格式 `%权重%文案`，例如 `%50%偶尔出现的句子` 的权重是普通条目的二分之一。使用自定义权重后按权重独立抽取，因此允许连续出现。被选中的条目之后仍会进行插件占位符替换和 `seal.format` 豹语解析。

竞技结算可通过 `对决胜利好感`、`对决失败好感`、`对决第二名好感` 和 `亡命神抽大满贯奖励` 修改。竞拍成交并盈利使用普通胜利好感，成交亏损使用普通失败好感；没有拍到箱子视为主动止损，不按排名扣好感。无论配置如何填写，代码都会强制保证失败扣除的绝对值大于第一名或1v1胜利收益，避免通过高胜率快速刷满好感。大满贯本身极难达成，因此不受普通对局的低增长限制。

刮刮乐奖金为 0、或钓鱼断线导致鱼获逃脱时，使用 `投入失败好感损失_10币`、`投入失败好感损失_50币`、`投入失败好感损失_100币`、`投入失败好感损失_500币` 四项配置。配置填写非负损失量，结算时统一转换为负好感；默认分别为 1、2、4、8。钓鱼只使用前三档。

每个游戏模块独立维护 `affectionGained`、`affectionLost` 和 `affection`，分别表示累计获得、累计失去和净变化。升级前已经完成的历史对局无法反推出逐模块好感来源，因此旧档案从升级后的第一场结算开始累计这三项数据。

## 判别式文案

档案与对局状态文案会同时判断好感和游戏币，各分为低、普通、高三档，共九种组合。默认边界如下：

| 维度 | 低 | 普通 | 高 |
| --- | ---: | ---: | ---: |
| 好感 | 小于 0 | 0 至 699 | 700 及以上 |
| 游戏币 | 小于 100 | 100 至 1999 | 2000 及以上 |

边界可通过四个 `判别式文案_*` 整数配置修改。九项 Template 配置从 `文案_判别_低好感_低金币` 到 `文案_判别_高好感_高金币`，不使用 `eval`，每种状态都会准确落入一个模板组。

所有模板支持插件占位符 `{name}`、`{dice}`、`{item}`、`{delta}`、`{coins}`、`{affection}`、`{relation}`；双色球、生死骰和借款文案还会按场景提供 `{tier}`、`{prize}`、`{entry}`、`{debt}`。替换后还会交给 `seal.format`，因此可继续使用海豹豹语表达式。
