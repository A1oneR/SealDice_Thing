# 骰娘好感度（小游戏合集）

这是一个面向 SealDice 1.4.5+ 的养成小游戏插件。好感度没有跑团规则上的实际作用，只用于关系阶段、文案变化和排行榜展示。

项目由两部分组成：

- `骰娘好感度小游戏合集.js`：必须安装的海豹单文件插件，保存全部钱包、档案、房间与游戏状态。
- `renderer/`：可选但推荐的本地图片排版服务。服务不可用时，插件会按配置回退为文字。

## 安装

1. 在海豹 WebUI 的 JS 插件页面上传 `骰娘好感度小游戏合集.js` 并启用。
2. 安装 Node.js 18+，进入 `renderer` 目录执行 `npm install`。
3. 执行 `npm start`，或在项目根目录运行 `启动图片服务.ps1`。
4. 保持插件配置 `图片服务地址=http://127.0.0.1:3891`。如海豹与渲染器不在同一台机器，请改成海豹能访问的地址。

渲染结果会短期缓存，并以 `[CQ:image,file=http://127.0.0.1:3891/api/image/<短ID>,cache=0]` 的单行 CQ 码发送，避免 Base64 填满海豹日志。默认缓存 10 分钟、最多 200 张。海豹和消息适配器在同一台机器时不必公开 3891 端口；若适配器运行在其他机器或容器中，请把“图片服务地址”配置为它能够访问的地址。

德州、亡命神抽、Farkle、爱赢一切和竞拍之王的多人房允许余额不足者以“游客”身份开房或加入。游客拥有正常座位、回合、牌面、骰子、暗标、助手、道具和最终排名，但不获得游戏币或好感，也不写入局数、胜负、项目分、最大牌型、大满贯或货品图鉴等任何永久档案。四个固定入场费模块的游客不扣入场费且人机单挑仍须足额支付；竞拍游客使用默认 500000 虚拟竞拍币，也可进入人机局体验。桌面与文字回退都会明确标记游客身份。

## 主要功能

- 德州扑克：2-6 人 PvP/PvPvE 或单人人机淘汰赛；付费玩家整场只支付一次 150，并以 150 桌面筹码作为容错率，小盲 25、大盲 50。每手底池结算后保留剩余筹码，发送 `.德州 下一手` 免费继续并轮转庄位；筹码归零才会退场，直到只剩一人仍有筹码才结算整场、好感与游戏币回报。多人按淘汰先后倒序排名；同一手多人归零时，入手筹码较多者排名较高，相同则按座位顺序稳定处理。PvE 群图会直接常亮真人手牌，但 Bot 决策仍只读取自身底牌与公共信息；PvP/PvPvE 继续隐藏未摊牌底牌。完整赌桌图会显示手数、中央五个公共牌槽、每人下注、底池、行动者与淘汰状态；阶段标签和行动日志独立居中，不会被手牌遮挡。整场结束后才可用 `.德州 下一局` 开始新一场，余额不足的多人房主会转为游客。
- 生化危机 7 二十一点：1-11 唯一数字牌、5 HP、多回合赌注伤害和完整王牌数据库；固定入场 100。轮到自己时可以连续使用王牌，只有摸牌或停牌才交出行动权。Bot 会对合法王牌进行收益评估，优先解爆、精确补点、逼迫爆牌、控场与增伤，并可在一次行动中连续出牌；每次响应设有动态上限，避免收割等补牌效果形成无限循环。17/21/24/27 点目标均使用独立的剩余牌分析：检查安全牌比例、精确数字是否仍在牌组、剩余牌组合能否凑到目标、至少需要几次摸牌，以及当前停牌是否已经领先；不可达的挑战目标和已经被抽走的数字王牌不会被浪费。爆牌后只禁止普通摸牌，仍可用王牌修正；Bot 的第一张暗牌在双方停牌结算前始终隐藏，不会因为换成 Bot 先手、Bot 停牌或爆牌而提前翻开，爆牌状态和相关日志提示也会保持隐藏。敌方获得新王牌时只显示数量，使用后才公开名称。双方连续停牌且中间没有其他操作时才结算。结算后会保留双方最终牌面、点数和伤害，下一回合由本轮输家先手，平局则交换先手；玩家发送 `.yan 21点 抽牌` 后才正式开局。未使用王牌跨回合保留，每回合各追加一张，普通摸牌默认有 25% 概率额外获得一张。
- 亡命神抽：2-6 人房间、十花色牌效、船锚保护、钥匙宝箱、大满贯；美人鱼、藏宝图、弯刀、钩子和大炮在存在合法目标时必须选目标执行，藏宝图必须获取一张翻出的牌；固定入场 100。专用桌面会绘制当前甲板、牌库/弃牌堆、强制效果目标，以及每名玩家十花色顶牌、分数和大满贯次数。
- Farkle 快艇骰：2-6 人房间，1v1 固定 5000 分；支持热骰、三对、顺子、三/四/五/六条；固定入场 100。帮助、等待、投掷、选择、存分与结算均使用专用快艇骰桌。玩家爆骰后 Bot 仍会按原逻辑自动完成行动，但返回画面会保留玩家上一组爆骰骰面用于回看，并显示 Bot 上一轮入账分数或 Farkle 结果；该回看不会写回真实回合状态。
- 爱赢一切：1v1 PvE/PvP 综艺牌局，固定入场100并转换为双方各20枚桌面筹码。49张牌由剪刀18、石头12、布12、爱6、骗子1组成；每轮依次进行初始发牌、第一轮下注、最终补牌、同步公开与宣告、第二轮下注和摊牌。每打满七轮或剩余牌不足时会换一副完整牌库，并把双方筹码向上取整减半后继续，直到一方筹码归零。所有玩家都可以宣告任意能由公共牌与已公开手牌补成的牌型，宣告不必符合自己的暗牌，普通牌手最终仍按真实四张牌摊牌。私人骗子牌会把合法宣告兑现为真实牌型，但同牌型相遇时骗子方直接落败，持骗子牌落败还会额外支付最多5筹码。公共骗子牌由双方独立指定。PvE 群图常亮玩家手牌，Bot 依旧看不到；玩家锁定后双方直接同时开牌。PvP 双方分别私聊提交 `.爱赢一切 公开 ...`，两边都锁定后回群发送 `.爱赢一切 确认公开`，牌桌才会同时展示双方选择。本轮结算会停留到玩家发送 `.爱赢一切 下一轮`。胜者返还200游戏币。
  - 第一轮若有人全押且对手完成跟注，系统会补发最终手牌并直接摊牌，跳过公开宣告和第二轮下注；私人骗子牌与公共骗子牌会自动选择最佳合法效果。
  - PvE Bot只使用自己应知的信息，会结合剩余牌数、公开位置、筹码、底池、轮次、对手宣告和历史下注倾向进行真报、诈唬、慢打与反加注。
- 彩票与风险栏目：保留 10/50/100/500 四种面额和四类实体刮刮票，单票奖金硬限制为面额的100倍。新增视频扑克的10/30/50三种机台：10币为J或更好并可用同一副剩余牌进行翻牌比大小，猜错后可从钱包额外支付当前待领奖金一半（向上取整）复活，待领奖金本身不减少；30币为所有2均可替代任意牌的狂野规则，50币为共用保留选择、分别补牌结算的五手扑克。赔率表、保留牌、五手结果、翻牌连胜、复活与Jackpot均直接绘制在专用赌场图片中。Jackpot从1000开始，刮刮栏目每笔有效下注的10%会注入奖池并保留小数。双色球从1-15选择5个不重复红球、从1-4选择1个蓝球；每日18:00静默开奖，开奖后可在下一次18:00前主动兑奖。生死骰以全部游戏币下注，简单模式5空1死、生还返还1.2倍，困难模式1空5死、生还返还3倍。双色球、生死骰和视频扑克均不改变好感。
- 借款：余额低于150时可领取150游戏币，每笔应还195；有未还借款时再次申请会递增扣除好感。任何收入使余额达到345后自动归还一笔195，并恢复该笔借款扣除好感的50%。申请、欠款和最近还款均使用独立账页图片。
- 钓鱼：小鱼塘/江水/大海三档成本，每个水域 16 种鱼，共 48 种图鉴。专用场景图会显示水域、钓鱼人物、钓竿与浮漂、最新鱼影、逐条鱼获卡、鱼篓估值、判断进度和断线风险。初次下竿的稀有/传说概率为 2.5%/0.25%，连续博弈只会小幅提高，最多五次判断。`.我的 钓鱼` 会显示历史最大鱼、历史最小鱼与图鉴解锁进度；只有安全收杆后仍在鱼篓中的鱼才会写入档案，断线鱼获不计入，并按水域投入扣除 1/2/4 好感。
- 竞拍之王：首次进入从 11 名差异化助手中选择搭档；助手已拆分为随机轮廓探测、品类鉴定、开局统计和区间估价。玛丽亚会自动统计低阶品质并估算回收价带，维克托自动统计高阶品质并在第3轮升级，艾哈迈德从货量、占格、大件数切入并逐步收窄整箱估价；这些报告只发给当前玩家，且只包含带误差的上下限，不公开精确成交总价。其余主动助手仍用 `.竞拍 技能` 发动，无需坐标。默认新手仓，也可前往六类特殊场地。每箱使用 12×10 战争迷雾货柜，约 7-24 件固定尺寸长方形货品；每轮公共探照灯固定公开4格，每名玩家每轮可私下探索1格，整件探开后才显示名称和插画。界面另按已经显示的货品计算保守最低估价。人机与最多八席 PvP/PvPvE 房保证至少三名 Bot 同台；每轮公开名次轨迹但继续隐藏对手金额，成交后从96种货品池逐件开箱并出售。竞拍币按1游戏币兑换10000竞拍币结算。
- 签到和投喂：每日低保与奖励均使用带日历、奖励卡、余额和关系进度的专用签到图；赠礼提供甜食、零食、饮品、餐点、生活用品、家具六类共 24 种礼物，菜单显示完整礼物架，成功与余额不足也有独立结果图。
- 玩家档案：新玩家必须先用 `.yan 注册 <名字>` 登记1至9个字的专属名；可用 `.yan 改名 <新名字>` 修改，当前房间、竞拍现场和钓鱼进度会同步。旧版本已有名字的档案会自动迁移。
- 分模块统计：八个游戏分别累计局数、胜负平、项目总分、最高纪录、金币净收益，以及好感获得、失去和净变化；德州额外记录历史最大牌型，爱赢一切额外记录胜轮、最高牌型、骗子牌胜负和罚筹码，竞拍额外记录资金、货品与图鉴指标。刮刮栏目额外统计视频扑克局数、手数、中奖手、投入、实收、最高奖金、最佳牌型、翻牌连中、复活及Jackpot；`.视频扑克 统计` 可打开专用统计面板，`.yan 我的 <项目>` 可打开彩色详细统计页。
- 排行榜：综合、好感、金币及八个项目榜；项目榜使用不同颜色区分胜、负、好感获得和好感失去，档案索引最多保留 10000 名玩家。
- 文案：八个关系等级、常用事件以及“低/普通/高好感 × 低/普通/高金币”的九宫格判别文案均使用海豹 Template 配置，可在 WebUI 直接替换。
- 随机文案池：所有 `文案_*` Template 配置都支持在 WebUI 点击“＋”添加任意数量的候选项。插件每次使用文案时都会读取最新列表并随机选择一条，自动忽略空项；默认等权且不会连续重复，也可写成 `%50%这条文案` 调低相对权重。使用自定义权重时按权重独立抽取，因此允许连续出现。修改后请先在 WebUI 保存。
- 投喂条件文案：无需新增配置栏，直接在 `文案_投喂` 的候选项前写条件。支持 `分类`、`好感`、`礼物`，例如 `分类=甜食;好感=高::骰娘开心地收下了{item}。`、`礼物=牛奶::骰娘捧起了{name}送来的牛奶。`；好感值使用 `低`、`普通`、`高`。多条件必须全部满足，匹配时优先抽取条件数量最多的一组，未命中则回退无条件候选。权重可组合为 `%50%分类=家具;好感=高::文案`。
- 状态图：德州使用完整六座赌桌，21 点使用上下对坐牌桌，亡命神抽使用十花色甲板桌，Farkle 使用带真实骰点和玩家进度卡的专用骰桌，爱赢一切使用五色手势牌与面对面筹码桌；视频扑克使用带置顶赔率、真实牌面、五手列表和翻牌进度条的赌场机台；刮刮票、双色球、生死骰和借款账页分别使用专用票面；钓鱼使用完整水域现场，竞拍使用夜间货场与开箱货柜双背景。

## 数据与备份

全部权威状态都在海豹扩展存储中，渲染器不保存玩家数据。主要键前缀：

```text
aff.profile.v1:       玩家钱包、好感与项目统计
aff.registry.v1       全局玩家索引
aff.room.v1:          群内各游戏房间
aff.scratch.ticket.v1 未刮彩票
aff.videoPoker.session.v1: 视频扑克进行中的手牌与翻牌状态
aff.videoPoker.jackpot.v1 视频扑克全局渐进奖池（保留小数）
aff.lottery.draw.v1:  双色球分期开奖数据
aff.lottery.draw.history.v1 最近60期全局开奖索引
aff.fishing.v1:       个人钓鱼进度
```

备份海豹数据目录即可一并备份。不要同时安装多个修改过扩展名但使用相同 `EXT_NAME` 的副本。

## 来源说明

本项目参考了同仓库的星际迷航德州、`deadmandraw_g.js`、`farkle骰子游戏.js`、`刮刮乐.js` 与 `21点生化危机.js` 的玩法和交互经验，但重新实现了统一存储、经济、房间、结算和图片输出层。已修正的重点包括：

- 德州七选五完整比较和边池结算。
- Farkle 四条分支在 `score` 初始化前使用导致的运行时错误。
- Farkle 选择中夹带不计分骰子的验证。
- 亡命神抽多步牌效长期挂起造成的群聊房间卡死风险。
- 21点“遗忘”重开后仍由骰娘先手时，Bot循环提前退出造成的行动权卡死。
- 刮刮乐原奖池与票价脱钩、可能突破合理上限的问题。

王牌名称与效果以用户提供的《第一部分：图片文字精准识别（王牌效果数据库）》为准。
