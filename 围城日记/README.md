# 围城日记

一个面向海豹骰的文字生存与据点建造插件。它借鉴了手机端生存游戏的节奏，但规则、事件、文案和渲染均为本项目原创。

## 目录

- `围城日记.js`：直接上传到海豹 WebUI 的单文件插件，负责存档、规则、事件、命令和图片调用。
- `server.js`：Node + Express + node-canvas 图片服务。默认监听 `3889`。
- `package.json`：图片服务依赖。
- `start.ps1`：Windows 下安装依赖并启动后端。
- `test/`：后端健康检查和渲染接口测试。

## 安装

1. 在本目录运行 `npm install`。
2. 运行 `npm start`，确认 `http://127.0.0.1:3889/health` 返回 `ok`。
3. 将 `围城日记.js` 上传到海豹，或复制到 JS 扩展目录。
4. 如果后端不在本机，把插件顶部 `BACKEND_URL` 改成可被海豹访问的地址。

## 核心命令

`.wjd help <1-4>` 查看四页图片帮助，`.wjd help <指令>` 查看该指令的图片化详细说明。

`.wjd tutorial` 查看三日新手教程。新周目默认开启，按实际操作自动勾选任务；`.wjd tutorial off/on` 可以关闭或重新开启提示。

`.wjd init` 创建新的周目，之后按提示使用 `.wjd choose 1` 选择背景、特质和装备。

开局背景为单选；特质和装备为多选点数商店。可以使用 `.wjd choose 1 2 5 8 13` 一次购买多个选项，系统按顺序结算。重复项和点数不足项会跳过，不影响后面的便宜选项。使用 `.wjd choose 2 5 8 0` 可以在购买后立即结束当前阶段。`.wjd choose page 2` 用于翻页。即使点数耗尽，图片中也会保留一个 0 点的“不再选择”装饰选项。

`.wjd start` 开始本周目；`.wjd status` 查看状态卡；`.wjd inventory <页码>` 查看分页背包，`.wjd item <名称>` 查看物资图鉴。

`.wjd use <物资>` 使用食物、饮水、药品等消耗品；`.wjd recipes <页码>` 查看配方，`.wjd craft <配方名或编号>` 制作。

`.wjd action 搜刮|休息|清剿|治疗|侦查|移动|出发` 推进时间。

`.wjd base` 查看据点，`.wjd build <编号>` 建造设施，`.wjd relocate <地图编号>` 搬迁据点，`.wjd map` 查看资源点，`.wjd goal` 查看逃离进度。

`.wjd legacy` 查看累计点数和可继承特质；`.wjd legacy buy <编号>` 在新周目开局时预装传承特质；`.wjd reset` 放弃当前周目（会保留累计点数）。

`.wjd weather` 查看天气修正；`.wjd skills` 查看技能经验；`.wjd quests` 查看日常委托；`.wjd survivors` 查看同伴；`.wjd rescue` 尝试营救幸存者。

## 设计说明

每天前三次行动属于常规时段。第三次行动后系统会提醒返回据点，但不会强制结束一天；第4次起仍可无限探索，每次额外行动都会增加疲劳层数、口渴消耗、伤口概率和遭遇风险。只有先使用 `.wjd action 返回` 回到据点，再使用 `.wjd action 休息`，才会结算食物、水、天气、感染、设施生产和夜袭，并进入下一天。

当前内容库包含百余种有重量、稀有度、分类、描述与用途的物资，20 余个地点、20 余个制作配方，以及大量固定事件和组合式搜刮文案。同一地点的开场、发现过程和撤离记录会按周目种子重新组合。

新手教程覆盖前三个游戏日：第一天学习状态、背包、地图、移动、搜刮、使用和休息；第二天学习据点、建造、配方、制作、治疗、天气和技能；第三天学习侦查、清剿、任务、幸存者、营救、撤离目标和日志。完成每日教程会获得保障性物资，完成三日教程会给予六项技能经验。

后端只负责图片渲染，不保存游戏状态；存档完全由海豹扩展存储保存。后端离线时插件会自动降级为文本输出，数据不会丢失。若服务器环境已经安装参考项目的 `node_modules`，可用 `NODE_PATH` 指向该目录临时启动；正式部署仍建议在本目录独立执行 `npm install`。
